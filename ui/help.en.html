Shortcuts

F1 … F4Show only session 1…4 (again = back to grid)
F5Back to the grid
F6New session (maximum of 4)
F7Close the current session (login and data are kept)
F8Switch between 2 and 4 sessions
F9Open the Lives window (muted tabs)
F11Toggle full screen
F12 / EscShow/hide this help
Shift+F1 … F4Open the session in its own window / return to the grid
Ctrl+Shift+F1 … F4Reset the session data (asks for confirmation)
Ctrl+RReload the session
Ctrl+Shift+RReload all sessions ignoring the cache
Ctrl+Alt+←/→Move the current session in the grid

Bottom bar and right-click

Click a tabShow only that session (click again = back to grid)
Double-clickRename the session (Enter saves, Esc cancels)
Right-clickOn a tab or inside the game: reload, rename, mute, zoom, own window, reset data, new and close session
🔊 / 🔇Mute only that session
✕Close the session. It comes back with its login saved when you click +
− 100% +Zoom of the selected session (50% to 200%). Less zoom gives the game more room in its pane

The numbers are the position in the grid (left→right, top→bottom). For Lives, log in to Twitch/Kick once (the login is saved) using the account linked in the game. The menu (☰ button) has language, live limit and live quality. Shortcuts work anywhere in the app, including the bar and the Lives window.
